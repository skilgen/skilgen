# Dashboard Guide

## `/dashboard`

Org overview with stats cards, score trend, repository table, and knowledge coverage.

## `/dashboard/repos`

Repository list with search, sorting, score badges, language, skill count, last analyzed time, and Analyse buttons.

## `/dashboard/repos/[id]`

Repository detail with overall score, four subscores, score history, dependency risk, coverage map, source filter, and skills table.

## `/dashboard/repos/[id]/skills/[id]`

Skill detail with raw `SKILL.md`, source type, score breakdown, freshness badge, version history, copy button, load count, and last loaded time.

## `/dashboard/analytics`

Usage analytics: total loads, unique skills loaded, top skills chart, never-loaded list, daily activity, and agent runtime breakdown.

## `/dashboard/registry`

Browse public skills, search by tag/name, view published skills, and import reusable skills.

## `/dashboard/sources`

Org-wide coverage map across all eight categories. Shows missing categories per repo and CLI commands to add sources.

## `/dashboard/upgrade`

Pricing and checkout entry point for Team and Business plans.

## `/dashboard/settings`

Organization settings: general threshold, Slack notifications, GitHub App status, webhook URL, recent deliveries, and billing portal.

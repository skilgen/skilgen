# Coverage Map

The coverage map measures whether a repository has skills across eight categories.

| Category | What it covers | Generated by |
|---|---|---|
| Codebase Architecture | Domains, files, services, dependencies | Code analysis, Terraform, Kubernetes, Helm |
| Code Style | Naming and implementation conventions | Code analysis |
| Testing Conventions | Test layout, commands, fixtures | Code analysis |
| Internal Tools | API specs and internal workflows | OpenAPI, GraphQL, Postman |
| Security Compliance | Findings, SBOMs, policy | SARIF, SBOM, SECURITY.md |
| Design System | UI components and visual conventions | Frontend analysis |
| Data Schema | Tables, models, streams | dbt, SQL schema, Kafka |
| Operational Knowledge | Runbooks and incidents | Runbooks, Confluence, Notion, postmortems |

Formula:

```text
(covered categories / 8) * 100
```

Improve coverage by adding sources:

| Missing Category | Command |
|---|---|
| Internal Tools | `skilgen analyze --source openapi` |
| Security Compliance | `skilgen analyze --source sarif` |
| Data Schema | `skilgen analyze --source dbt` |
| Operational Knowledge | `skilgen analyze --source runbooks` |

Find the map on `/dashboard/sources` and on each repository detail page.

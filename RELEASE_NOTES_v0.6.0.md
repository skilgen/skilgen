# Release Notes v0.6.0

## Highlights

- evidence-backed architecture synthesis
- richer source comprehension with symbol, call, runtime, and test mapping
- `skilgen diff`, `skilgen score`, and analytics as continuous quality signals
- enterprise skills, MCP governance, and private-source ingestion
- architecture graph exports in Mermaid, JSON, and HTML

## Why it matters

Skilgen now behaves less like a static generator and more like a living operating system for coding agents. It can explain architecture, detect drift, score skill quality, and keep repo-local context aligned with real code changes.
